# Contribuir a AI Sysadmin

Podés informar errores, proponer mejoras y enviar cambios. El proyecto es gratuito; aportar dinero no es necesario para contribuir ni usarlo.

- Explicá el problema, la versión y cómo reproducirlo, usando datos sintéticos y registros revisados. No publiques credenciales, IP privadas de clientes, capturas sensibles ni claves.
- Para desarrollar, seguí [AGENTS.md](AGENTS.md), [distribución Windows](docs/WINDOWS_DISTRIBUTION.md) y [versiones](docs/WINDOWS_UPDATES.md). Incluí las pruebas y documentación afectadas.
- Conservá los avisos y licencias de terceros. Solo enviá trabajo propio o autorizado para distribuir bajo sus términos. Las contribuciones intencionales al código original se reciben bajo Apache 2.0 según LICENSE, salvo acuerdo explícito distinto.
- No cambies la visibilidad, el historial, el canal de actualización o la licencia de terceros como parte incidental de una contribución.

Para contactar al mantenimiento o consultar cómo apoyar, usá el [sitio oficial de Sentra IT](https://sentrait.com.uy/). Por ahora ese enlace no implica que exista una cuenta de donaciones habilitada.
