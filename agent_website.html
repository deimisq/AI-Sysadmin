Instalación Rápida

Descargar el paquete

$ curl -O https://agent.sentrait.com.uy/ai-sysadmin-release.tar.gz

Descomprimir

$ tar -xzf ai-sysadmin-release.tar.gz && cd dist

Ejecutar instalador interactivo

$ ./install.sh

El instalador te guiará paso a paso para configurar dominio, SSL y crear el usuario administrador.

Requisitos del Servidor

  • Sistema Operativo: Linux (Ubuntu 20.04+ o Debian 11+ recomendado)
  • Docker Engine 20.10 o superior
  • Docker Compose v2 o superior
  • 4GB RAM mínimo (8GB recomendado)
  • 10GB de espacio en disco
  • Puertos 80 y 443 disponibles
