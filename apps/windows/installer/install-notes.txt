AI Sysadmin Agent - Windows x64

Incluye el runtime .NET. Requiere Microsoft Edge WebView2 Runtime Evergreen.
No necesita un backend ni una cuenta para las conexiones locales.

Se instala para el usuario actual, sin solicitar privilegios de administrador.
El ejecutable se actualiza en una ruta fija; se retiran las carpetas antiguas
por versión de esa instalación. El instalador solicita el cierre normal solo
de sus propias instancias. Si no confirma el cierre, aborta antes de sustituir
archivos, sin forzar la salida. El cierre desconecta las sesiones SSH/RDP.
Al finalizar puede abrirse la versión nueva, según la opción seleccionada.

La app consulta actualizaciones. Descargar, preparar la instalación y reiniciar
requieren aprobaciones independientes. La sustitución de archivos se realiza
tras aprobar el reinicio de la app. Windows no se reinicia automáticamente.
Para migrar desde un cliente antiguo con carpetas por versión, ejecuta este
instalador una vez con la app cerrada; después usa el actualizador integrado.

El inventario, las credenciales, la configuración IA y los registros permanecen en
%LOCALAPPDATA%\AiSysadmin y se conservan al desinstalar.
Crea una copia cifrada desde Conexiones → Exportar / importar conexiones antes
de cambiar de equipo o usuario. El inventario protegido con DPAPI requiere la
misma cuenta Windows. La copia portable permite migrar conexiones y carpetas
con su contraseña; no incluye claves IA, chats ni tokens de GitHub.

La conexión con un proveedor IA se configura en Ajustes y requiere aceptar
el aviso de envío de datos. El instalador no configura ni consulta una IA.

Esta compilación no está firmada con un certificado comercial.
Windows puede mostrar una advertencia de publicador desconocido.
No se ofrece reversión automática de cambios realizados por el agente.

El idioma seleccionado en el instalador se guarda para la aplicación.
No se traducen nombres de equipos, comandos ni salidas de terminal.
