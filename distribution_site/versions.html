🔄 Cómo Actualizar tu Instalación

Método 1: Actualización Automática (Recomendado)

Si instalaste desde el paquete oficial, ya tienes el script de actualización:

$ cd /opt/dist
$ ./update.sh

El script automáticamente:

  • Crea un backup de tu base de datos
  • Descarga la última versión
  • Actualiza las imágenes Docker
  • Reinicia los servicios
  • Aplica nuevas migraciones de BD

Método 2: Actualización Manual

Si prefieres control total sobre el proceso:

# 1. Backup de la base de datos
$ docker compose exec postgres pg_dump -U sysadmin sysadmin_db > backup.sql

# 2. Descargar nueva versión
$ curl -O https://agent.sentrait.com.uy/ai-sysadmin-release.tar.gz

# 3. Extraer
$ tar -xzf ai-sysadmin-release.tar.gz

# 4. Cargar nuevas imágenes
$ for img in dist/images/*.tar.gz; do docker load < "$img"; done

# 5. Actualizar configuración (preserva tu .env)
$ cp dist/docker-compose.yml .

# 6. Reiniciar servicios
$ docker compose down && docker compose up -d

# 7. Aplicar migraciones
$ docker compose exec backend alembic upgrade head

⚠️ Importante: Tu archivo .env con la configuración nunca se sobrescribe durante la actualización. Si hay cambios que requieran nueva configuración, se anunciarán en el changelog.
